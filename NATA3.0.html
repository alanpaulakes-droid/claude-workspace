Banco de series de entrenamiento

EDITABLE · RITMOS TOMADOS DE CSS Y SPRINTER

Cada serie usa el CSS (pestaña Natación · CSS) o el test de Sprinter (pestaña Sprinter) para calcular el ritmo objetivo real, según la zona y la distancia escrita en la notación. Filtrá por fase ATR, agregá series propias, y mandalas a un día del mesociclo.

Formato de la columna Serie: 4x50 d20 (4 reps de 50m, 20" descanso entre reps)  ·  4x100 c/1:30 (saliendo cada 1:30, intervalo en vez de descanso puro)  ·  compuesta: 2x(4x50 d20) D4min (2 bloques de 4x50 d20, 4min de descanso ENTRE bloques — "d" minúscula = entre reps, "D" mayúscula = entre bloques)

Las descripciones fisiológicas, de descanso y de aplicación práctica de las tablas se pueden reescribir directamente sobre la celda.
